# Decisions

Calls made while rebuilding the project, with the reason for each. Newest last.

| # | Decision | Why | Alternatives considered |
|---|---|---|---|
| 1 | Run everything on one Kubernetes cluster built with kind, driven by `make up`. | The request was "through kubernetes". kind is installed, runs on one machine, and the same manifests work on a real cluster. | k3s or k3d (not installed); Docker Compose (not Kubernetes). |
| 2 | Traefik v3 for ingress. | Kubernetes ingress-nginx was retired in March 2026. Traefik has native forward-auth middleware and CRDs. | Gateway API with another controller. |
| 3 | Authelia forward-auth as the only login, with identity passed to apps in `Remote-*` headers. | One sign-in for Storage, Todo, Stirling PDF and Grafana. Apps don't handle passwords. Header spoofing is blocked twice: a strip middleware runs before forward-auth, and NetworkPolicies admit app traffic only from Traefik pods. `make smoke` proves both. | Each app with its own accounts; full OIDC in every app (more code per app, same security). |
| 4 | `lab.localhost` as the local domain. | Browsers, curl and systemd-resolved send `*.localhost` to loopback without DNS or `/etc/hosts` edits. CoreDNS rewrites it to Traefik inside the cluster. | nip.io (depends on outside DNS); `.test` (needs `/etc/hosts`). |
| 5 | The storage server is custom Go + React, not Filebrowser or Nextcloud. | It needs sharing between friends, public links, quotas and an in-browser viewer, with metrics and traces that match the rest of the platform. Off-the-shelf servers expose little telemetry. | Filebrowser (the old stack), Nextcloud (heavy), Seafile. |
| 6 | File contents live on a host directory (`DATA_DIR`) mounted into kind; metadata in PostgreSQL through CloudNativePG; nightly `pg_dump` backups to the host. | Files and backups survive `make down`. Restore is one command. | Object storage (MinIO's community distribution changed in 2025; Garage or SeaweedFS add another stateful system). |
| 7 | The todo app is TypeScript (Fastify, Drizzle, React), like the earlier Todo_App project. | Matches the stack the user already used for todos. Two languages also prove the observability contract is language-neutral. | Go for both apps. |
| 8 | Observability is kube-prometheus-stack, Loki, Tempo and Alloy, with one metric naming contract for every app. | One dashboard covers both apps' HTTP traffic. Traces start at Traefik and continue through the apps into PostgreSQL. | OpenTelemetry Collector instead of Alloy; Jaeger (the user's Overall_Infra project removed it in favour of Tempo). |
| 9 | Grafana, Prometheus, Alertmanager and the Traefik dashboard are admins only. | Logs and traces contain usernames and file names. Friends get the apps, not the telemetry. | Grafana Viewer role for everyone. |
| 10 | Share tokens are redacted from Traefik access logs, app logs and trace attributes. | A public link is a capability; it shouldn't sit in Loki or Tempo for a week. | Keeping logs complete and relying on admin-only access. |
| 11 | Every request that changes state needs `X-Requested-With: fetch` and, when `Origin` is present, an exact origin match. No CORS. | Sibling subdomains share the session cookie's site, so SameSite alone doesn't stop a page on `pdf.lab.localhost` from posting to `storage.lab.localhost`. | CSRF tokens (more state, same protection here). |
| 12 | User-uploaded HTML, SVG and XML are never served inline. PDFs render with pdf.js; Markdown renders with raw HTML disabled. | An uploaded page running on the storage origin could call the API as the viewer. | A separate user-content domain (more DNS and TLS setup). |
| 13 | Stirling PDF runs in namespace `pdf` under Pod Security `baseline`. | It can't run as non-root. All other app namespaces are `restricted`. | Building a custom non-root Stirling image. |
| 14 | Storage previews Office files by converting them through Stirling PDF. | Uses the PDF service already in the cluster instead of shipping LibreOffice twice. | No Office preview. |
| 15 | Design direction "shared shelf" by Claude Fable: IBM Plex Sans self-hosted, one accent spine per app. | One visual language across Home, Storage and Todo. Rendered contrast was measured with Playwright (1272 text elements, both themes). Only one mockup-only element failed: text inside a fake PDF page, which pdf.js replaces with a canvas. | System font stack. |
| 16 | The kind CA key is kept in `.local/` across rebuilds. | You trust the CA once in your browser instead of after every `make up`. | Regenerating it each time. |
| 17 | Host data directories are world-writable (`0777`). | hostPath volumes ignore `fsGroup`, and the apps run as different non-root users. `.local/` itself is mode 700. | Per-app ownership set by a privileged init step. |
| 18 | The todo API was built by Codex and the todo web UI by Claude Opus. | The model controller couldn't read Claude's usage when the todo task was due, and the rules hand implementation to Codex when Claude is unavailable. The web UI stays with Opus because frontend work runs through `/frontend-design`. | Waiting for Claude's telemetry to recover. |
| 19 | A public link's download limit counts whole-file downloads only. Previews and resumed downloads (a positive `Range` offset) don't count. | Guests can open the viewer and resume a dropped download without burning the allowance. The Codex review closed the gaps where `bytes=00-`, suffix ranges, a stale `If-Range` or `HEAD` either skipped the count or wasted it. | Counting every byte served (resumes and previews would use up links). |
| 20 | The Home portal hides Grafana and the admin links from non-admins, using `GET /api/me`. | Friends saw links that Authelia refused. Authelia still enforces access. | Showing every link to everyone. |
| 21 | Traefik caps concurrent logins at 6 and Authelia gets 1 GiB of memory. | A k6 run with 20 VUs logging in at once OOM-killed Authelia (argon2id uses 64 MiB per check), which signed every user out. The same burst from an attacker would do it too. Extra logins now get `429` and retry. | Cheaper argon2 parameters (weaker against offline cracking); Redis-backed sessions (survive restarts but not the outage). |
